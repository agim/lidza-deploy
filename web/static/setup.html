1. Claim this installation

Run sudo cat /var/lib/lidza-control/setup-token on your server and paste the key below. This proves you own the server and prevents anyone else from claiming its first administrator account. An SSH tunnel is needed only when accessing a localhost installation from another computer.

3. PostgreSQL

Managed PostgreSQL uses Docker, a private password, persistent storage and a loopback-only port. It is reused when setup is retried.

4. Domain and HTTPS

Use HTTPS for a public installation. A local http://127.0.0.1 address is supported for development.

This address was chosen during installation. Public installations use automatic HTTPS; localhost stays local.

The token is used for this DNS change and is not retained. The record is created without Cloudflare proxying.

DNS must resolve to this server before setup can finish. Stale A or AAAA records must be removed.

5. GitHub

After setup, open Integrations and choose Connect GitHub. Approve your deployment app, then choose which repositories it may access.

No OAuth client ID or secret to copy. Your local operator account is separate from GitHub. Public repositories can deploy without connecting. GitHub integration requires a public HTTPS control-panel address; localhost installations cannot receive GitHub callbacks or automatic deployment webhooks.
